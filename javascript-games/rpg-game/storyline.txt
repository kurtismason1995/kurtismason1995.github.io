RPG Main Story Chapter Flow

This file defines the current chapter structure with concrete progression flags and battle gates.

Chapter 1: Intro (Home to Old Man)
- Theme: Personal stakes and first commitment.
- Start flag: CHAPTER_1_INTRO_STARTED.
- Completion flag: CHAPTER_1_INTRO_COMPLETE.
- Existing supporting flags: SEEN_INTRO, SEEN_OLDMAN_CUTSCENE.
- Core beats:
	- Sam learns Dad is missing (Home intro cutscene).
	- Sam receives Rocky.
	- Old Man grants a second partner and points Sam east.
- Gate to next chapter:
	- Completing Old Man sequence sets CHAPTER_1_INTRO_COMPLETE and starts mid chapter.

Chapter 1: Mid (Town Hall Conspiracy)
- Theme: Discovery and rising threat.
- Start flag: CHAPTER_1_MID_STARTED.
- Completion flag: CHAPTER_1_MID_COMPLETE.
- Existing supporting flags: SEEN_SOCIALROOM_SCENE, ARENA_INVITATION, INVITATION_ACCEPTED.
- Core beats:
	- Sam witnesses Tony and Sandy conflict in Social Club Room.
	- Sam receives tournament invitation tied to Dad's location.
	- Gate guard verifies invitation and grants arena entry.
- Gate to next chapter:
	- Invitation accepted sets CHAPTER_1_MID_COMPLETE and CHAPTER_1_CLIMAX_STARTED.

Chapter 1: Climax (Hay Tournament Gauntlet)
- Theme: Direct confrontation through escalating trials.
- Start flag: CHAPTER_1_CLIMAX_STARTED.
- Completion flag: CHAPTER_1_CLIMAX_COMPLETE.
- Existing supporting flags: SEEN_ARENA_CUTSCENE, DEFEATED_ENEMY_1..4.
- Chapter-end battle gate:
	- Must defeat enemy1, enemy2, enemy3, enemy4 before boss unlock.
- Core beats:
	- Arena reveal confirms Dad is captive.
	- Sam clears four challengers to reach the leader.
- Gate to next chapter:
	- Defeating the fourth challenger sets CHAPTER_1_CLIMAX_COMPLETE and CHAPTER_1_FINALE_STARTED.

Chapter 1: Finale (Boss and Rescue)
- Theme: Payoff and liberation.
- Start flag: CHAPTER_1_FINALE_STARTED.
- Completion flag: CHAPTER_1_FINALE_COMPLETE.
- Existing supporting flag: DEFEATED_BOSS.
- Chapter-end battle:
	- Boss battle in Arena against boss team.
- Core beats:
	- Sam defeats the leader.
	- Dad is freed and family arc resolves.
	- Home and town post-victory dialogue opens.

Global completion marker
- CHAPTER_1_COMPLETE is set after the boss defeat to mark the end of the main arc currently implemented.

Implementation notes
- Keep legacy flags for backward compatibility with existing saves.
- New chapter flags should be additive and set at milestone cutscene points.
